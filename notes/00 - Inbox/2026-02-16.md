- Inner loop
    - the things that happen on your machine before you push your code.

    - "I rarely test my code, but when I do, it's in production." (this is a joke)
- System Integration (End to End) tests TEND to be "black box tests"
    - use other testing tools / languages than the system they are testing
    - PLyawright - browser automation testing tool - use typescript (can use C#)
- Unit tests and unit integration tests are "white box tests"
    - "clear box" - these tests are written in the same language as the system under test, they have a reference to the assembly, create instances of class, call methods
    - they know "how the bread is buttered" so to speak, how the sausage is made
    - in other words, they break encapsulation
